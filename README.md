# 💡 LightTracker - Система моніторингу електроенергії

IoT проект для відстеження відключень світла через WiFi датчик. Ідеально для моніторингу ситуації вдома, коли ти не вдома!

## 🎯 Можливості

- 📊 Реальний час моніторингу стану світла
- 📈 Статистика відключень (коли, як довго, скільки разів)
- 📱 Web dashboard (працює на телефоні)
- 🌐 Доступ з будь-якої точки світу
- 💾 Історія всіх відключень
- 📉 Графіки та аналітика

## 🛠 Необхідне обладнання

### Варіант 1: Фоторезистор (простіший)
- **ESP8266** (NodeMCU, Wemos D1 Mini) або **ESP32** - $2-5
- **Фоторезистор** (LDR) - $0.5
- **Резистор 10kΩ** - $0.1
- USB кабель для живлення

### Варіант 2: Датчик напруги (точніший)
- **ESP8266** або **ESP32** - $2-5
- **AC-DC модуль** або **оптопара** - $1-2
- Для підключення до 220V (будь обережний!)

### Варіант 3: Найпростіший (рекомендований)
- **ESP8266/ESP32** - $2-5
- **USB зарядка** підключена до мережі
- Датчик просто реєструє чи є WiFi з'єднання = чи є світло

## 🚀 Швидкий старт

### 1. Backend (сервер)

```bash
cd backend
npm install
npm start
```

Сервер запуститься на `http://localhost:3000`

### 2. Frontend (dashboard)

Відкрий `frontend/index.html` в браузері або hosted на сервері.

### 3. Датчик (ESP8266/ESP32)

1. Встанови **Arduino IDE**
2. Додай ESP8266/ESP32 board
3. Відкрий `sensor/light_sensor.ino`
4. Налаштуй WiFi credentials та IP сервера
5. Завантаж на плату

### ⚠️ Важливо: Роутер на UPS?

Якщо твій роутер працює від безперебійника або акумулятора, WiFi буде працювати навіть без світла!
У такому випадку потрібен інший підхід. Детальніше: **[docs/UPS_ROUTER.md](docs/UPS_ROUTER.md)**

Основні варіанти:
- 🔄 Подвійний ESP (один на UPS, один без) - найпростіше
- 💡 ESP + Фоторезистор на powerbank - працює завжди
- ⚡ Датчик напруги 220V - найточніше

## 📡 API Endpoints

```
GET  /api/status        - Поточний стан світла
GET  /api/history       - Історія відключень
GET  /api/stats         - Статистика
POST /api/sensor/update - Оновлення від датчика
```

## 🌍 Доступ з інтернету

Для доступу з iPhone коли не вдома:
- Використай **ngrok** (безкоштовно): `ngrok http 3000`
- Або налаштуй **port forwarding** на роутері
- Або задеплой на **Railway/Render/Heroku**
