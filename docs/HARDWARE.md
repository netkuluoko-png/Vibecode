# 🔌 Апаратна частина LightTracker

## Варіанти реалізації

### ⚡ Варіант 1: Фоторезистор (Найпростіший) - Рекомендований

Визначає наявність світла за рівнем освітленості в кімнаті.

**Компоненти:**
- ESP8266 (NodeMCU, Wemos D1 Mini) - $2-5
- Фоторезистор (LDR) - $0.5
- Резистор 10kΩ - $0.1

**Схема підключення:**

```
         3.3V
          |
          |
        [LDR]
          |
          +-----> A0 (ESP8266)
          |
        [10kΩ]
          |
         GND
```

**Налаштування в коді:**
```cpp
#define SENSOR_TYPE 1
#define LDR_PIN A0
#define LIGHT_THRESHOLD 512  // Підбери під своє освітлення
```

**Переваги:**
- ✅ Дуже просто
- ✅ Дешево
- ✅ Не потрібно лізти в електропроводку

**Недоліки:**
- ❌ Реагує на денне світло
- ❌ Треба розмістити біля лампи

---

### 🔌 Варіант 2: Підключення до USB (Найлегший)

ESP8266 просто підключений до USB зарядки в розетці. Якщо є WiFi підключення = є світло.

**Компоненти:**
- ESP8266 - $2-5
- USB зарядка
- Micro USB кабель

**Принцип:**
Коли вимикається світло в квартирі, вимикається і USB зарядка. ESP8266 втрачає живлення та WiFi підключення. Коли світло повертається - ESP підключається знову та відправляє сигнал.

**Налаштування в коді:**
```cpp
#define SENSOR_TYPE 3  // WiFi only mode
```

**Переваги:**
- ✅ Абсолютно без пайки
- ✅ Не потрібні додаткові компоненти
- ✅ 100% точність

**Недоліки:**
- ❌ ESP має бути підключений до розетки що вимикається зі світлом
- ❌ При першому запуску після повернення світла - невелика затримка

---

### ⚠️ Варіант 3: Детекція 220V (Складніший, для досвідчених)

Безпосередня детекція наявності напруги 220V в мережі.

**Компоненти:**
- ESP8266 - $2-5
- AC-DC модуль 220V → 5V - $1-2
- Оптопара PC817 - $0.3
- Резистори

**⚠️ УВАГА! Робота з 220V небезпечна! Якщо не впевнений - не роби!**

**Схема підключення:**

```
220V AC ---[Резистор 100kΩ]---[Міст випрямлювач]---[Оптопара]--- D1 (ESP8266)
                                                         |
                                                        GND
```

**Налаштування в коді:**
```cpp
#define SENSOR_TYPE 2
#define DIGITAL_PIN D1
```

**Переваги:**
- ✅ Точно визначає наявність 220V
- ✅ Не залежить від освітлення

**Недоліки:**
- ❌ Складніше
- ❌ Небезпечно без досвіду
- ❌ Треба лізти в проводку

## Збірка (Варіант 1 - Фоторезистор)

### Крок 1: Підключення

1. З'єднай один кінець фоторезистора до **3.3V** на ESP8266
2. Другий кінець фоторезистора до піна **A0**
3. З піна A0 через резистор 10kΩ до **GND**

Якщо є breadboard - просто встав все в макетну плату.

### Крок 2: Програмування

1. Завантаж **Arduino IDE** з https://arduino.cc
2. Додай ESP8266:
   - File → Preferences
   - Additional Board Manager URLs: `http://arduino.esp8266.com/stable/package_esp8266com_index.json`
   - Tools → Board → Boards Manager → пошук "ESP8266" → Install

3. Встанови бібліотеку **ArduinoJson**:
   - Tools → Manage Libraries → пошук "ArduinoJson" → Install

4. Відкрий файл `sensor/light_sensor.ino`

5. Налаштуй WiFi та сервер:
   ```cpp
   const char* WIFI_SSID = "TviyWiFi";
   const char* WIFI_PASSWORD = "TviyParol";
   const char* SERVER_URL = "http://192.168.1.100:3000/api/sensor/update";
   ```

6. Підключи ESP8266 до комп'ютера через USB

7. Обери плату:
   - Tools → Board → NodeMCU 1.0 (ESP-12E Module)
   - Tools → Port → вибери свій COM порт

8. Натисни **Upload** (→)

### Крок 3: Тестування

1. Відкрий Serial Monitor (Tools → Serial Monitor)
2. Встанови швидкість **115200**
3. Побачиш лог підключення та дані

### Крок 4: Розміщення

Розмісти датчик біля лампи або там де є світло коли включене електропостачання.

## Калібрування

### Підбір порогу для фоторезистора:

1. Відкрий Serial Monitor
2. Побачиш значення: `Рівень світла: 523`
3. Виміряй значення при **увімкненому світлі**
4. Виміряй значення при **вимкненому світлі**
5. Встанови `LIGHT_THRESHOLD` посередині між цими значеннями

**Приклад:**
- Світло увімкнене: 800
- Світло вимкнене: 200
- Встанови: `#define LIGHT_THRESHOLD 500`

## Troubleshooting

### Не підключається до WiFi
- ✅ Перевір SSID та пароль
- ✅ ESP8266 працює тільки на WiFi 2.4GHz (не 5GHz!)
- ✅ Перевір чи роутер увімкнений

### Не відправляє дані на сервер
- ✅ Перевір IP адресу сервера
- ✅ ESP та сервер мають бути в одній мережі
- ✅ Перевір чи сервер запущений: `http://IP:3000/api/health`

### Фоторезистор не реагує
- ✅ Перевір підключення
- ✅ Подивись значення в Serial Monitor
- ✅ Підбери LIGHT_THRESHOLD

### ESP8266 постійно перезавантажується
- ✅ Перевір живлення (має бути 5V 1A мінімум)
- ✅ Використай якісний USB кабель
- ✅ Спробуй інший USB порт

## Додаткові можливості

### Кілька датчиків

Можеш встановити кілька датчиків у різних кімнатах:

```cpp
const char* SENSOR_ID = "kitchen";  // Замість "main"
```

### Battery backup

Додай powerbank або батарею до ESP8266 щоб він працював навіть при відключенні світла:

```
Powerbank → ESP8266 (через USB)
ESP8266 підключений до WiFi на UPS або 4G роутері
```

Так датчик буде працювати навіть без світла!
